# Initialisation

## download

install [git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) if you don't have it

```bash
git clone https://github.com/lyesrabhi16/Projet_AIE.git
```

execute these from root folder

## install the dependencies

install [Nodejs and npm](https://kinsta.com/blog/how-to-install-node-js/) if you don't have them

```bash
npm install --prefix backend
npm install --prefix frontend

```

## start the backend server

```bash
npm run backend
```

## start the frontend website

```bash
npm run frontend
```
